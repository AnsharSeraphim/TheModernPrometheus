# docs/

This folder contains repository-level narrative documentation.

## Contents

- `release_notes.md`: Unreleased and shipped change log for user-facing and tooling-facing updates.

## How to use this folder

- Update `release_notes.md` whenever repository behavior, automation workflows, or contributor expectations change.
- Keep entries focused on observable outcomes (what changed and why it matters), then cross-link implementation files when needed.
